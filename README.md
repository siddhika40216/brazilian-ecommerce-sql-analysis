# Brazilian E-Commerce SQL Analysis

## Overview

A SQL-based business analysis of the **Brazilian E-Commerce Public Dataset by Olist**, developed using MySQL to investigate sales performance, customer behavior, product trends, payment patterns, seller performance, and delivery operations.

The analysis uses a range of SQL techniques, from basic aggregations and joins to window functions, date analysis, conditional logic, and subqueries, to answer practical business questions from the dataset.

## Dataset

The analysis uses five Olist datasets:

| Dataset                        | Description                               |
| ------------------------------ | ----------------------------------------- |
| `olist_orders_dataset`         | Order details, status, and timestamps     |
| `olist_order_items_dataset`    | Products, sellers, prices, and freight    |
| `olist_order_payments_dataset` | Payment methods, installments, and values |
| `olist_products_dataset`       | Product categories and product attributes |
| `olist_customers_dataset`      | Customer and location information         |

The imported data contains approximately **99K orders, 112K order items, 103K payment records, 32K products, and 99K customers**.

## Business Analysis

### Sales & Revenue

* Total revenue and freight cost
* Average order value
* Highest-value orders
* Monthly revenue performance
* Order value compared with overall average
* Revenue contribution of the top 10 orders

### Customer Analysis

* Customer-level revenue
* Repeat customers
* Customers without orders
* Highest-spending customers
* Highest-value order for each customer

### Product & Seller Analysis

* Product categories by sales volume
* Category-level average selling price
* Seller ranking by total sales

### Payment Analysis

* Most frequently used payment method
* Payment value segmentation using `CASE`

### Order & Delivery Analysis

* Monthly order volume
* Average items per order
* Delivered and cancelled order percentages
* Average delivery time
* Orders delivered later than the estimated date

## SQL Techniques

The project applies:

* Aggregation: `SUM()`, `COUNT()`, `AVG()`
* Filtering: `WHERE`, `HAVING`
* Grouping and sorting: `GROUP BY`, `ORDER BY`
* Table relationships: `JOIN`, `LEFT JOIN`
* Conditional logic: `CASE`
* Date processing: `STR_TO_DATE()`, `MONTH()`, `DATEDIFF()`
* Numeric functions: `ROUND()`, `ABS()`
* Window functions: `RANK()`, `ROW_NUMBER()`
* Subqueries

## Selected Business Questions

Examples of questions addressed in the analysis:

* Which customers generate the highest total spending?
* Which product categories have the highest sales volume?
* Which payment method is used most frequently?
* What percentage of orders are delivered or cancelled?
* Which month records the highest sales revenue?
* Which sellers rank highest by total sales?
* What is the highest-value order for each customer?
* How much of the total sales revenue is generated by the top 10 orders?

## Running the Analysis

1. Set up a MySQL database named `olist_ecommerce`.
2. Import the Olist CSV datasets into their respective tables.
3. Open `sql/olist_business_analysis.sql` in MySQL Workbench.
4. Execute the queries to reproduce the analysis.
